# 🚀 My Portfolio

স্বাগতম! এটি আমার ব্যক্তিগত পোর্টফোলিও ওয়েবসাইট। এই প্রোজেক্টের মাধ্যমে আমি আমার স্কিল, শিক্ষাগত যোগ্যতা এবং বিভিন্ন প্রজেক্ট প্রদর্শন করেছি।

## ✨ ফিচারসমূহ (Features)
- **Modern UI/UX:** আকর্ষণীয় এবং আধুনিক ইউজার ইন্টারফেস।
- **Responsive Design:** মোবাইল, ট্যাবলেট এবং ডেস্কটপসহ সব ডিভাইসে পারফেক্টলি অপ্টিমাইজড।
- **Splash Screen:** ওয়েবসাইট লোড হওয়ার সময় একটি সুন্দর অ্যানিমেটেড স্প্ল্যাশ স্ক্রিন।
- **Project Showcase:** আমার তৈরি করা সেরা প্রজেক্টগুলোর তালিকা এবং লাইভ লিঙ্ক।
- **Contact Form:** সরাসরি যোগাযোগ করার জন্য একটি ফাংশনাল কন্টাক্ট সেকশন।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)
- **Frontend:** Next.js / React.js, JavaScript
- **Styling:** CSS / Tailwind CSS
- **Deployment:** Vercel / Netlify
